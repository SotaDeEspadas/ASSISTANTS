# ASSISTANTS

> **WebApp para Asistentes de Banca Privada**
> Soporte operativo a Private Bankers de Banco Mediolanum

---

## 📌 Descripción

**ASSISTANTS** es una aplicación web diseñada para digitalizar y optimizar el trabajo de los **asistentes de banca privada** en Banco Mediolanum.

---

## 🚀 Getting Started

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/SotaDeEspadas/ASSISTANTS.git
   cd ASSISTANTS
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:5173`
